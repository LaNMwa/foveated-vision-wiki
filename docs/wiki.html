EVIDENCE-BASED REVIEW

用三個問題防止把不同研究混在一起

FOVEA 會讓 Sensor 少讀 Pixels 嗎？

從 FOVEA 原文不能推論這件事。它透過已取得影像的非均勻重取樣調整模型的輸入。見 P2，PDF p.1–2。

RPR 的節省究竟發生在哪裡？

RPR 在商用 Sensor 的 Raster Stream 之後選擇性編碼，改善後續 DRAM 的 Traffic 與 Memory Footprint。見 P3，PDF p.1–2。

TuMag 的欄位 ROI 在 FIFO 前還是後？

論文中的 FPGA 先重排，再在 image_tx 根據欄起點與長度控制輸出，因此需分開評估前級 FIFO 與後級 Data TX。見 P4，PDF p.8–13。
