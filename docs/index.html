WORKFLOW · FIRST GRAPH

第一版 Graph：已有檢查與失敗回路

先建立資料與 Wiki，再規劃教學大綱、檢索文獻、生成第一版完整 HTML，進行基本檢查；失敗時回到大綱與摘要重新修訂。

實際檢查後，為什麼修改成 V2？

ADJUSTMENT 01

增加 Evidence Coverage Gate

發現：V1 引用五篇論文，但逐頁主張與原文對應的密度仍可改善。
修改：在產生大綱前建立 Claim → Paper/Page 對照表。

ADJUSTMENT 02

增加 Teaching Gate

發現：V1 資料完整，但初學者仍可能把 Sensor Readout 與 DRAM 交通量混淆。
修改：加入資料層級地圖、情境推演與誤解練習。

ADJUSTMENT 03

增加 Browser Gate

發現：原本只看有沒有輸出 HTML，無法保證互動、翻頁與小螢幕可用。
修改：新增多頁驗證與 ROI 試算，保留可重跑檢查記錄。
